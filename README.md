# Shan Strong 2026 Website

This is the finalized GitHub Pages package.

## Main design choices

- Pearl gray background
- White content cards
- Ellis navy and breast cancer pink palette
- Real pink breast cancer ribbon SVG graphics
- No emoji ribbons, bows, or yellow awareness ribbons
- "Playing for a Purpose" homepage message
- "Inspired by Shannon's Strength" story section
- "In Partnership With" wording for the Foundation for Ellis Medicine
- No fundraising thermometer
- No donation buttons
- No 2026 sponsors listed yet

## Before launch

1. Replace the temporary Ellis Foundation artwork with the official approved logo if needed.
2. Replace `REPLACE-WITH-YOUR-EMAIL` in `index.html`.
3. Update the event date, prices, and payment links in `script.js`.
4. Add 2025 tournament photos in the `assets` folder and replace the gallery placeholders.

## Upload to GitHub

Unzip the package and upload the files inside it directly to the repository root:

- index.html
- styles.css
- script.js
- README.md
- assets/

Do not upload the enclosing folder itself.
